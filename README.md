# Repositorio de Infraestructura - Equipo Individual
## Descripción
Orquestación multi-capa con redes aisladas para el Centro de Cómputo.
## Requisitos
- Debian 13 (Trixie)
- Docker Engine v29+
## Cómo Desplegar
```bash
docker compose up -d
```

## Notas adicionales
- Despliegue verificado en entorno individual de Patty.
